About PremCall

S

@suryasticsai · Maker

PremCall is a secure, peer‑to‑peer voice calling app built with WebRTC. It lets you call your friends directly — no middlemen, no tracking.

📖 How to use

  • Register — Enter your name and a 10‑digit phone number. Verify with the OTP (use 123456 for demo).
  • Call — Tap any contact or dial a number manually. Press the green call button.
  • Incoming calls — Answer or reject with the overlay buttons.
  • During a call — Mute, speaker, or hang up using the call screen controls.
  • Check status — Use the Check button in the dialer to see if a number is online.

🔒 Privacy first

Your number is locked after verification. Calls are direct and encrypted via WebRTC. No call data is stored on any server.
